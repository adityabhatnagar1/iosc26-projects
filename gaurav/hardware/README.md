# Hardware Requirements

This is a **software-only project** — no special hardware, microcontrollers, or sensors are required.

## Minimum System Requirements

| Component | Minimum Specification | Purpose |
|---|---|---|
| Processor | Any dual-core CPU (e.g., Intel/AMD, ARM) | Running the Python interpreter |
| RAM | 2 GB | Comfortable for Python 3.x + editor |
| Storage | 50 MB free | Python installation + project files |
| Display | Any standard monitor | Viewing the menu interface and results |
| Input | Keyboard | Entering text, keys, and menu choices |

## Tested On

| Machine | OS | Python | Result |
|---|---|---|---|
| Personal Laptop (Intel i5, 8 GB RAM) | Windows 11 | 3.12 | All tests passed, program runs as expected |
| Lab PC | Ubuntu 22.04 | 3.10 | All tests passed, program runs as expected |

## Notes

- No internet connection is needed at runtime (the program uses only Python's built-in features).
- No budget was required — the project was completed on an existing laptop within the assigned lab schedule.
